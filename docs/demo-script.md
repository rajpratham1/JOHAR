# JOHAR — Demo video script (3–4 min)

Goal: show the full worker journey → certification → verification → compliance, and make the **AR**, **offline**, **language**, and **blockchain** points land clearly.

## Setup before recording
- One mid-range Android phone (test ARCore support beforehand; if unsupported, the fallback mode is fine and worth showing).
- Airplane mode ready to toggle (to prove offline).
- Dashboard open on a laptop; verify portal open in a second tab.
- Pre-load the Fire & Explosion module so assets are cached.

## Shot list

**0:00–0:20 — The problem (voiceover + stat card)**
"48 fatal mine accidents in Jharkhand in 2022–23, many involving workers with under 30 days of orientation. Classroom retention is below 20%. JOHAR fixes this."

**0:20–0:45 — Onboarding & language**
Open app → phone-OTP login → **switch language to Santali (Ol Chiki)** → tap the speaker icon to show **voice narration**. Emphasise: built for low-literacy tribal recruits.

**0:45–1:45 — AR training (the star)**
Open **Fire & Explosion Response** → point camera at the room → virtual fire + exit-route overlay appears → follow the PASS extinguisher steps in AR → complete the evacuation sequence. Narrate that this is markerless, no headset, on a normal phone.

**1:45–2:10 — Offline proof**
Toggle **airplane mode ON** → continue/redo a module → it still works. "No signal underground? No problem."

**2:10–2:40 — Assessment → certificate**
Take the module quiz (image/audio-based) → pass → certificate generates on-device with a **QR code**.

**2:40–3:10 — Blockchain anchoring & verification**
Toggle network back ON → certificate anchors (show the tx hash / link) → **scan the QR** from the verify portal → shows ✅ authentic + the on-chain proof. Then edit a field in the DB to show it flips to ❌ (tamper-evident).

**3:10–3:40 — Admin dashboard**
Switch to the dashboard → completion rates, **certification-expiry pipeline**, **site-wise risk**, weak-topic analytics, export report. "This is what a DGMS officer sees."

**3:40–4:00 — Close**
Recap: AR, offline, Hindi+Santali+voice, blockchain-verified certs, compliance dashboard. "JOHAR — every worker, safe."

## Tips
- Keep a **recorded backup** of the AR + blockchain segments in case of live flakiness.
- Show real device UI, not an emulator, for the AR parts.
